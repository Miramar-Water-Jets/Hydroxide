Microcontroller: Teensy 4.1 (l, w, h = 61.66, 17.78, 4.07) $mm^3$ 

Sonar System is an Audio System. It will take sound input from microphone array and then amplify it. Then it will try to find how far the sound is coming from.

Project will be a PlatformIO.

Physics (Doppler Effect):
1. Speed of sound in medium
2. Speed of pinger = ~0m/s
3. Frequency of pinger
4. Frequency heard by microphone array
